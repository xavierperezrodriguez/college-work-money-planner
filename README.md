# College / Work / Money Planner

A Python console application that compares different work scenarios and estimates how each one affects a student's college funding gap.

## Why I Built It

College planning involves several financial factors at the same time, including tuition, scholarships, savings, work income, and living expenses.

I built this project to create a simple way to compare different work scenarios and understand how each option could affect a student's financial situation.

## Features

- Calculates remaining college cost after scholarships or financial aid
- Calculates estimated income based on hourly wage, hours per week, and weeks worked
- Calculates living expenses over a selected period
- Compares multiple work scenarios
- Identifies the scenario with the strongest projected financial result
- Validates negative financial and work values

## How It Works

The user enters:

- Total college cost
- Scholarships or financial aid
- Current savings
- Monthly living expenses
- Number of months
- Different work scenarios

For each work scenario, the program calculates estimated work income, available money, and the final projected surplus or funding gap.

After comparing all valid scenarios, the program displays the strongest option.
